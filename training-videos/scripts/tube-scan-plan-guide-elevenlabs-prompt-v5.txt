Tee-see-gee Calibration for Normal Beam Inspection.

In this video, you will learn how to create, verify, and save a tee-see-gee setup in ScanMaster.

...

Before you start. Prepare six items.

The ScanMaster system. A normal beam probe. A calibration block with at least three eff-bee-aitch reflectors. The correct material velocity for the material. A stable water path. And access to Teach In mode.

Once everything is ready, open the ScanMaster Wizard.

...

On the calibration block, three eff-bee-aitch standards at different depths. We'll work from near to far.

Standard one - near. Standard two - middle. Standard three - far.

...

Open the ScanMaster Wizard. From the main menu, click Teach In.

A new screen image appears. The instrument window plus the Setup Toolbox dialog.

...

First, set the basic parameters. Four fields.

One. Material velocity. From the material database, select the material you're inspecting.

Two. Range. Set the range until you see the back wall.

Three. Gain. Verify the response from the three sixty-fourths inch eff-bee-aitch.

Four. Water path. Set seventy-six millimetres, or set the transducer-to-surface distance so the second front reflection does not appear between the first front and first back reflections.

...

Important.

Keep the water path consistent, within plus or minus one quarter inch, during standardisation, initial scanning, and final evaluation.

Deviation beyond plus or minus a quarter inch requires re-standardisation.

...

Before we set anything else, understand what tee-see-gee is solving.

Before tee-see-gee, three identical flat-bottom holes, three different signal heights. Closer means stronger. Farther means weaker.

After tee-see-gee, all eff-bee-aitch responses adjusted to eighty per cent eff-ess-aitch. One reference level. One pass-fail criterion. Across depth.

That is our goal. Let's build it.

...

Inside the Setup Toolbox, click the tee-see-gee tab. The tee-see-gee table appears.

Before any other action, verify three checkboxes on the right side of the tee-see-gee tab.

Active. Visible. Drag. All three must be checked. If Drag is off, you cannot drag the yellow dots in the next steps.

...

The same action, repeated three times. Set Point one - near eff-bee-aitch at eighty per cent eff-ess-aitch. Set Point two - middle eff-bee-aitch at eighty per cent eff-ess-aitch. Set Point three - far eff-bee-aitch at eighty per cent eff-ess-aitch.

Drag yellow dot. Eighty per cent eff-ess-aitch. Save. Three times.

...

Move the probe to the first eff-bee-aitch, the near standard.

On the A-scan, drag the yellow dot onto the response peak.

Adjust the Gain so the eff-bee-aitch amplitude reaches eighty per cent eff-ess-aitch. As you turn Gain up, the trace rises. Stop when the peak touches the cyan reference line.

Save Point one. Click the save button on the toolbar setup.

Node one - locked.

...

Move the probe to the second eff-bee-aitch, the middle standard.

Drag the second yellow dot onto the new response peak.

Adjust Gain so this peak also reaches eighty per cent eff-ess-aitch.

Save Point two.

Node two - locked.

...

Move the probe to the third eff-bee-aitch, the far standard.

Drag the third yellow dot onto the response peak.

Adjust Gain to eighty per cent eff-ess-aitch.

Save Point three.

Node three - locked. Three reference points set.

One detail from the guide.

With more than three segments, scroll boxes appear to the right of the segment list. The active segment is marked with an arrow next to its number.

...

If your inspection extends to full part depth, add a tee-see-gee point on the back-wall response.

Click the toolbar button to set the first point before the back-wall pulse. Then the second point after the back-wall pulse.

Create at least four points in total to define the tee-see-gee curve through the back-wall response.

Optional. Skip this step if your inspection only covers the eff-bee-aitch depth range.

...

Now save the tee-see-gee setup. Four clicks.

One. Click the Files tab in the Setup Toolbox.

Two. Under tee-see-gee, click Save.

Three. The you-pee-arr-dee-bee Navigator dialog opens. The default file path is displayed at the bottom.

Four. Name the file. We recommend a naming convention that includes the probe type, the eff-bee-aitch size, and the date. For example - Normal Beam underscore tee-see-gee underscore three sixty-fourths eff-bee-aitch underscore today's date. Click Save.

Tee-see-gee setup saved.

...

Quick checklist before you run the inspection.

Teach In opened. Material velocity set. Range set. Water path kept within plus or minus a quarter inch. Three eff-bee-aitch responses set to eighty per cent eff-ess-aitch. Optional back-wall points added if needed. Tee-see-gee setup saved.

Your tee-see-gee is ready. Run the inspection.

...

If you need to recalibrate after a probe change, a material change, or any deviation in water path, return to step three.

The full Scan Plan documentation is available in the Scan Plan tab.
