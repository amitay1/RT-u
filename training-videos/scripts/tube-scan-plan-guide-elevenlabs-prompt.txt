[matter-of-fact] T-C-G calibration in thirteen steps. The guide is in your hand. The screens are in this video.

Welcome to the Tube Scan Plan Guide. Normal Beam T-C-G Calibration.

[confident] In six minutes you'll set up a complete T-C-G calibration. Open the wizard. Place the probe on the Hagit block. Set three F-B-H peaks to eighty per cent. Add a back-wall point. Save.

Following the official ScanMaster Scan Plan Guide, step by step.

The guide opens with two prerequisites.

One. A minimum of three flat-bottom holes — F-B-H — three sixty-fourths inch diameter. Or as required, with different distances between them.

Two. A calibration block. Either the Hagit block, or a custom block meeting A-M-S Standard E-twenty-one-fifty-four — same as A-S-T-M E-one-twenty-seven — with three F-B-H.

The P-D-F references both standards by name. They're equivalent for this purpose.

Step three. Open the ScanMaster Wizard. Press Teach In.

Step four. A new screen image appears. This is your T-C-G calibration workspace.

Step five. To create T-C-G — start from the basic parameters dialog box.

Step six. Set all the parameters. From the basic ones first.

Step seven. Move to the Hagit calibration block. Place the probe.

Step eight. Material velocity. This step has three sub-parts.

Eight-A. Range. Set the range until you get the back wall.

Eight-B. Gain. Verify response from the three sixty-fourths inch F-B-H.

Eight-C. Water path. Set seventy-six millimetres of water path.

Or, more precisely — the distance from the transducer face to the part front surface must be such that the second front reflection does not appear between the first front and first back reflections.

[serious] The guide is explicit about water path.

Water travel must be the same within plus or minus one quarter inch — for standardisation, initial scanning, and final evaluation.

If your water path drifts beyond that, your calibration is invalid.

Step nine. Set a minimum three-position calibration block — F-B-H three sixty-fourths inch diameter — according to A-M-S Standard E-twenty-one-fifty-four, A-S-T-M E-one-twenty-seven, or your custom block meeting the same criteria.

Step ten. Move to the first position. Standard number one.

Ten-A. On the A-scan, drag the yellow dot onto the response peak. Set the Gain so the F-B-H amplitude reaches eighty per cent F-S-H.

Ten-B. Save the first point. Click the save button on the toolbar setup.

First T-C-G node locked.

Step eleven. Move to the second calibration standard. Set the response from the F-B-H to eighty per cent F-S-H.

Eleven-A. Drag the second yellow dot onto the response peak. Adjust Gain so the response reaches eighty per cent F-S-H.

Eleven-B. Save the second point. Click the save button on the toolbar.

Second T-C-G node locked.

Step twelve. Move to the highest calibration standard. Set the response from the F-B-H to eighty per cent F-S-H.

Twelve-A. Drag the third yellow dot onto the response peak. Adjust Gain to eighty per cent F-S-H.

Twelve-B. Save the third point on the toolbar setup.

One detail from the guide. When you have more than three T-C-G segments, scroll boxes appear to the right of the segment list. The currently active segment is indicated by an arrow next to its number.

Step thirteen. If needed — set another T-C-G point on the back-wall response. Adjust the gain to get eighty per cent F-S-H.

Thirteen-A. Click the button on the toolbar to set the first point before the back-wall pulse. Then set the second point after the back-wall pulse.

Thirteen-B. Create additional points — at least four total — to define the T-C-G curve from the back-wall point.

This step is optional. Use it when your inspection extends to the full part depth.

Step thirteen point one. Saving T-C-G.

Click save on the setup dialog box, T-C-G section.

From the middle of the Files tab, under T-C-G, click Save. The U-P-R-D-B Navigator Save dialog appears, with the default file path displayed at the bottom.

Name your calibration. Click Save.

Recap. Open the wizard, Teach In. Set basic parameters. Place probe on the Hagit block. Range, Gain, water path of seventy-six millimetres. Three F-B-H peaks each set to eighty per cent F-S-H. Optional back-wall node. Save through the Files tab T-C-G section.

Your T-C-G is ready. Run the inspection.
