Encrypt Download URL

Generates an AES-GCM encrypted blob that you paste into the landing page. Without the access code, the URL cannot be recovered — not even with full source-code access.

  1. Upload your .exe to Google Drive (or Dropbox). Right-click → Share → Anyone with the link.
  2. For Google Drive, click Copy link. The link looks like https://drive.google.com/file/d/<long-id>/view?usp=sharing.
  3. Convert it to a direct-download URL: replace /view?usp=sharing with /uc?export=download → https://drive.google.com/uc?export=download&id=<long-id>.
  4. Paste that direct-download URL below, along with your access code.
  5. Copy the resulting encrypted blob and paste it into index.html (the ENCRYPTED_DOWNLOAD constant).

This URL is what users will be redirected to after entering the correct code. Make sure it actually downloads when opened directly (not the file viewer).

Case-sensitive. This is what you'll give to your customers. Anyone with this code can decrypt the URL.
